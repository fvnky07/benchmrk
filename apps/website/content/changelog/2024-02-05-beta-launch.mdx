We're excited to announce the beta launch of Benchmrk! This release includes all core functionality needed for early adopters.

## Beta Features

### Core Platform

- User registration and profile management
- Basic benchmark creation
- Data visualization with charts

### UI/UX Improvements

- Dark mode support with next-themes
- Smooth animations using Framer Motion
- Accessible components built with Radix UI

## Known Issues

- Some edge cases in data export (being fixed)
- Mobile responsiveness needs polish on tablets
- Performance optimization for large datasets
