Our first alpha release is here! This is a limited release for internal testing and select users.

## Alpha Highlights

### Foundation

- Built on Next.js 16 with React 19
- Convex backend for real-time data
- TypeScript for type safety

### Basic Features

- User authentication flow
- Simple benchmark creation
- Basic data display

## Next Steps

We're gathering feedback from alpha testers to improve the platform before beta. Key focus areas:

- UI polish and consistency
- Performance optimization
- Bug fixes and stability

Thank you to all our alpha testers!
