Welcome to the first release of Benchmrk! This marks an exciting milestone as we launch our platform for tracking performance metrics and benchmarks.

## Key Features

### Authentication System

- Secure user authentication powered by Better Auth
- OAuth integration for seamless sign-in
- Session management with Convex backend

### Dashboard

- Real-time metrics visualization
- Interactive charts with Number Flow animations
- Responsive design that works on all devices

### Performance Tracking

- Create and manage custom benchmarks
- Track performance over time
- Export data for analysis
